# Phase 3 移动端发布准备实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Android release 签名与构建配置、添加 iOS 工程基线、实现状态栏/安全区/返回键/键盘适配、补齐深色模式，使应用达到可构建 signed APK/AAB 与可上架 iOS 的工程状态。

**Architecture:** 在现有 React + Capacitor 8 基础上，通过 Gradle 配置与 Capacitor 插件完成原生发布与平台适配；前端侧使用 Tailwind `env(safe-area-inset-*)` 与独立 theme store 处理安全区和主题切换，保持业务组件改动最小化。

**Tech Stack:** React 19 + TypeScript 5.9 + Vite 8 + Tailwind CSS 3 + Capacitor 8 + Gradle + Xcode

## Global Constraints

- 竖屏 Portrait -only（Android + iOS）。
- iOS 仅做工程基线，不配置签名团队。
- Android 使用自动生成的内测 keystore，密码不写入仓库，通过环境变量注入。
- `versionName` 与 `versionCode` 必须跟随 `package.json` 的 `version`。
- 所有新增代码必须通过 `npm run lint && npm run format:check && npx tsc -b --noEmit && npm run test:run && npm run build`。
- Capacitor 插件调用需静默降级，避免 Web 预览崩溃。

**Interfaces:**

- Produces: `versionName` string from `package.json` version

- [ ] **Step 1: 编写版本号计算脚本**

Create `scripts/android-version.mjs`:
```js
import { readFileSync } from 'fs';
import { resolve } from 'path';

const pkgPath = resolve(process.cwd(), 'package.json');
const pkg = JSON.parse(readFileSync(pkgPath, 'utf-8'));
const [major, minor, patch] = pkg.version.split('.').map(Number);
const versionCode = major * 10000 + minor * 100 + patch;

process.stdout.write(`${versionCode}\n`);
```

- [ ] **Step 2: 在 build.gradle 中读取版本号**

Modify `android/app/build.gradle`:
```gradle
def getVersionCode() {
    def code = new ByteArrayOutputStream()
    exec {
        commandLine 'node', '../../scripts/android-version.mjs'
        standardOutput = code
    }
    return code.toString().trim().toInteger()
}

def getVersionName() {
    def name = new ByteArrayOutputStream()
    exec {
        commandLine 'node', '-e', "console.log(require('../../package.json').version)"
        standardOutput = name
    }
    return name.toString().trim()
}

android {
    ...
    defaultConfig {
        ...
        versionCode getVersionCode()
        versionName getVersionName()
    }
}
```

import { useEffect } from 'react';

export function useSafeArea(): void {
  useEffect(() => {
    const update = () => {
      const style = document.documentElement.style;
      style.setProperty('--sat', `${env(safe-area-inset-top)}`);
      style.setProperty('--sar', `${env(safe-area-inset-right)}`);
      style.setProperty('--sab', `${env(safe-area-inset-bottom)}`);
      style.setProperty('--sal', `${env(safe-area-inset-left)}`);
    };
    update();
    window.addEventListener('resize', update);
    return () => window.removeEventListener('resize', update);
  }, []);
}

```ts
import { useEffect } from 'react';
import { App } from '@capacitor/app';
import { useNavigationStore, type Page, TAB_PAGES, type Tab } from '@/stores/navigationStore';

export function useBackButton(exitApp: () => void): void {
  const { currentPage, activeTab, navigateTo } = useNavigationStore();

  useEffect(() => {
    const listener = App.addListener('backButton', ({ canGoBack }) => {
      if (!canGoBack) {
        exitApp();
        return;
      }
      if (TAB_PAGES.includes(currentPage as Tab)) {
        exitApp();
      } else {
        navigateTo(activeTab);
      }
    });

    return () => {
      listener.then((l) => l.remove());
    };
  }, [currentPage, activeTab, navigateTo, exitApp]);
}
```

- [ ] **Step 1: 创建 theme store**

Create `src/stores/themeStore.ts`:
```ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

export type ThemeMode = 'system' | 'dark' | 'light';

interface ThemeState {
  mode: ThemeMode;
  setMode: (mode: ThemeMode) => void;
  resolvedTheme: () => 'dark' | 'light';
}

function getSystemTheme(): 'dark' | 'light' {
  if (typeof window === 'undefined') return 'dark';
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

export const useThemeStore = create<ThemeState>()(
  persist(
    (set, get) => ({
      mode: 'system',
      setMode: (mode) => set({ mode }),
      resolvedTheme: () => {
        const mode = get().mode;
        return mode === 'system' ? getSystemTheme() : mode;
      },
    }),
    {
      name: 'flash-theme',
      version: 1,
      partialize: (state) => ({ mode: state.mode }),
    }
  )
);
```
